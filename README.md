# PeerSync Website Prototype

A simple HTML, CSS, and JavaScript prototype for the PeerSync student community forum research project.

## Run it
1. Extract the ZIP file.
2. Keep `index.html`, `styles.css`, `app.js`, and `sti-cubao-logo.png` together in the `peersync-website` folder.
3. Double-click `index.html` to open it in a modern browser.

## Prototype features
- Community feed with demo posts, likes, comments, search, and reporting
- Discussion forums and Q&A with answered/unanswered indicators
- Group spaces and demo messaging
- Participation points and leaderboard
- Notifications, profile, and appearance settings
- Demo moderation view for faculty/moderators
- STI College Cubao logo and a minimalist blue-and-yellow design

## Important limitations
This is a front-end demonstration. It does not authenticate real STI or Microsoft 365 accounts, store shared data on a server, or provide secure role-based access. Demo activity is stored locally in the browser. A real multi-user deployment needs a backend, database, secure authentication, server-side permissions, and proper privacy and moderation controls.
